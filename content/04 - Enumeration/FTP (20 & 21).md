This protocol work with the support browser or email client to perform their services.

## Downloading File
```bash
ftp> ls
ftp> get Important\ Notes.txt
```
- Use ls to list the directory
- Use get to download the file

## Download All available file using Wget
```bash
wget -m --no-passive ftp://anonymous:anonymous@10.129.14.136
```
- We use wget to download file from server use HTTP or HTTPS
- -m enable infinite recursion. Keeping directory listing, preserve timestamp and check file size before re-download
- --no-passive forced wget to use Active Mode instead Passive Mode
- ftp:// specify the ftp
- anonymous:anonymous the ftp credential
