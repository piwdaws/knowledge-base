## Overview
- When we got into a system. Sometime we notice no prompt is presence
- BUT we can still issue a command.
- That shell is non-tty shell

---

## Non TTY Shell
- A non-TTY shell may allow commands to execute without providing a normal interactive terminal.
- Depending on how the session was established, this can limit interactive behaviour and interfere with programs that expect a terminal.

---

## TTY and PTY
- **TTY:** A terminal interface through which a user interacts with a shell.
- **PTY:** A pseudoterminal, which provides a terminal-like interface through a software-controlled terminal pair.
- **Interactive shell:** A shell designed for interactive command input and output.
