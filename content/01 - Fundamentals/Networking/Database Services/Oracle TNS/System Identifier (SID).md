## Common Default Oracle SIDs

| SID Name              | Description / Environment     | Common Usage                                                                    |
| :-------------------- | :---------------------------- | :------------------------------------------------------------------------------ |
| **`XE`**              | Oracle Express Edition        | The absolute most common default in labs and lightweight environments.          |
| **`ORCL`**            | Enterprise / Standard Edition | The standard factory-default name for standard database installations.          |
| **`PROD`**            | Production Environment        | Commonly used for a company's live, primary business database server.           |
| **`DEV`**             | Development Environment       | Used by programmers to test and build software features.                        |
| **`TEST`**            | Testing / QA Environment      | Used for quality assurance checks before moving updates to production.          |
| **`ORCL1` / `ORCL2`** | Multi-instance setups         | Numbered variations used when a single host runs multiple Oracle databases.     |
| **`DB11G` / `DB12C`** | Version-specific setups       | Named directly after the software version version footprint (e.g., 11g or 12c). |
