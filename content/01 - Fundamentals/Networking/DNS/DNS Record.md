## What is DNS Record
- An instruction stored on a server that connects a human-readable domain name to a computer-readable IP address or provides routing rules for services like email.
- Like contact card or phonebook for the internet

---
## Type of Record

| Record | Purpose                                     |
| ------ | ------------------------------------------- |
| A      | Domain → IPv4 address                       |
| AAAA   | Domain → IPv6 address                       |
| CNAME  | Alias → another hostname                    |
| MX     | Mail server                                 |
| NS     | Authoritative nameserver                    |
| TXT    | Arbitrary text; often SPF/DKIM/verification |
| SOA    | Zone authority information                  |
| PTR    | IP → hostname (reverse DNS)                 |
