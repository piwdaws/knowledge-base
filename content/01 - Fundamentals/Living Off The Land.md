## Definition 
Living off the Land (LotL) is the use of legitimate tools already present on a system to perform actions beyond their intended administrative purpose. 

---
## Why It Matters 
Attackers can abuse trusted/native utilities instead of introducing additional tools onto the target. 

---
## Common Functions 
- File Download 
- File Upload 
- Command Execution 
- File Read 
- File Write 
- Security Bypass
