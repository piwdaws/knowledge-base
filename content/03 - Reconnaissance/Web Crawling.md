## Definition
- Crawling (spidering) is the automated process of systematically browsing a website by following links and collecting information.

---
## How it works

1. Start with a seed URL. 
2. Fetch the page. 
3. Parse the page. 
4. Extract links. 
5. Add discovered links to a queue. 
6. Visit discovered pages. 
7. Repeat.
