## What is Automated Reconnaissance?
- Automated reconnaissance uses tools and frameworks to perform repetitive reconnaissance tasks automatically. 
- Instead of manually running each reconnaissance technique, automation can combine multiple tasks into a single workflow.

---
## Advantages 
- **Efficiency** — performs repetitive tasks faster 
- **Scalability** — can investigate many targets 
- **Consistency** — follows predefined procedures consistently 
- **Coverage** — can combine multiple reconnaissance techniques 
- **Integration** — connects different tools and data sources

---
## Tasks That Can Be Automated Automated reconnaissance may include: 
- DNS enumeration 
- Subdomain enumeration 
- Web crawling 
- Directory enumeration 
- Port scanning 
- WHOIS lookups 
- HTTP header analysis 
- SSL/TLS information gathering 
- Web archive discovery
