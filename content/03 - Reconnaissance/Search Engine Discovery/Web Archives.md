## What are Web Archives
- Web Archives stores historical snapshot of a website, allow us to view content that existed way earlier back then
- A well known one is the https://web.archive.org/

---
## Wayback Machine 
The Wayback Machine archives snapshots of publicly accessible webpages over time. A snapshot can preserve parts of a website such as: 
- HTML 
- CSS 
- JavaScript 
- Images 
- Documents 
- Page structure

---
## Why this important?
The wayback machine unveil a website past. Like
- Uncovering Hidden asset and vulnerabilities that might still have
- Tracking changed and identifying pattern 
- Gather Intelligence like target past activities, marketing strategies or past employee
- Stealthy Reconnaissance because it doesnt directly interact with the server itself
