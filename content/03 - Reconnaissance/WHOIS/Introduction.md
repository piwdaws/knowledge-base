## What is WHOIS
- a query/response protocol used to retrieve registration information about internet resources, primarily **domain names**, but also information related to **IP address allocations** and **autonomous systems**.
- Useful during passive recon

---
## Why use WHOIS

| Information            | Purpose                                                             |
| ---------------------- | ------------------------------------------------------------------- |
| Domain Name            | Confirm the target domain                                           |
| Registrar              | Identify the company managing the domain registration               |
| Registrant             | Identify the registered organization/person when publicly available |
| Administrative Contact | Identify domain administration contacts                             |
| Technical Contact      | Identify technical contacts                                         |
| Creation Date          | Determine when the domain was registered                            |
| Expiration Date        | Determine registration expiry                                       |
| Name Servers           | Identify DNS infrastructure associated with the domain              |
| Domain Status          | Identify registration/transfer/update restrictions                  |
