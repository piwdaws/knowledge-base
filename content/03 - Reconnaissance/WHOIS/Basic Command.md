## Query a domain
```bash
whois <domain name>
```
```bash
# Example Output
Domain Name: inlanefreight.com 
Registry Domain ID: 2420436757_DOMAIN_COM-VRSN 
Registrar WHOIS Server: whois.registrar.amazon 
Registrar URL: https://registrar.amazon.com 
Updated Date: 2023-07-03T01:11:15Z 
Creation Date: 2019-08-05T22:43:09Z
```
--- 
## What to look for

### 1. Registrar

```
Registrar: <registrar>
```
- Identifies the organization through which the domain is registered.

### 2. Registrant

```
Registrant Organization: <organization>
```
- May identify the organization responsible for the domain.
- Personal information may be hidden behind a privacy service.

### 3. Registration Dates

```
Creation Date: <date>
Updated Date: <date>
Registry Expiry Date: <date>
```
- Useful for understanding the history and age of the domain.

### 4. Name Servers

```
Name Server: ns1.example.com
Name Server: ns2.example.com
```
- Can provide clues about the target's DNS infrastructure.

### 5. Domain Status

Examples:

```
clientTransferProhibited
clientUpdateProhibited
clientDeleteProhibited
```
- These indicate restrictions placed on domain operations.
